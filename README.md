#MAISON STORE — Multi-Brand Streetwear & Designer Store

A multi-brand streetwear and designer clothing mini e-commerce storefront built with **Lovable**, designed to showcase an end-to-end shopping flow from catalog filtering and item specs to checkout and order status tracking.

## Live Demo

* **Live Demo:** https://pixel-perfect-snapshot-8144.lovable.app

## Features

* **Thin Horizontal Header:** Sticky top navigation bar with smooth transitions for **Catalog**, **Cart**, and **My Orders** views.
* **Catalog & Filtering:** Filter items across categories (*Bags, Jackets, Beanies/Hats, Neck Gaiters/Buffs, Sweaters/Zip-ups, T-Shirts, Hoodies*) and brands (*Dior, Guess, Stone Island, C.P. Company, Adidas, Lacoste, Maison Margiela, Puma, Moncler*).
* **Product Details:** Size selection and smooth expand/modal views showing fabric composition, fit notes, care instructions, and item details.
* **Cart & Checkout Flow:** Add or remove items, adjust quantities, calculate totals and shipping, apply promo code **`VIP15`**, and test purchases via **Stripe** (test mode) or **Demo Instant Pay** backed by **Supabase**.
* **Order Tracking:** View placed orders and their current statuses inside the orders tab.

## Visual & UI Direction

* **Color Palette:** Deep titanium dark surfaces, midnight navy accents, and crisp white highlights with clean rectangular white buttons.
* **Typography & Motion:** Minimalist Apple-inspired typography, subtle 3D depth effects, and smooth transitions for scrolling, tabs, and item descriptions.

## Tech Stack

* **Frontend / Builder:** Lovable
* **Backend & Database:** Supabase
* **Payments:** Stripe (Test / Demo flow)

## Notes

* Built as a portfolio showcase with a demo/test payment flow so visitors can test the full purchase and order tracking experience without real payment details.
* Connecting live production keys, payment webhooks, and database access rules is required before going live with real transactions.
